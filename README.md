# Live Weather Dashboard

## Overview

The Live Weather Dashboard is designed for quick and easy weather checks in any city. Users simply enter a city name to receive instant updates on temperature, humidity, and wind speed. The application displays both current conditions and a five-day forecast, presented in a clear and visually appealing format. The dashboard is lightweight, responsive, and optimized for use across desktops and mobile devices[web:43][web:46].


## Features

- Instantly displays current weather for any city
- Five-day weather forecast
- Shows temperature, humidity, and wind speed
- Clean, user-friendly and responsive layout
- Fast search and intuitive navigation


## Technologies Used

- HTML
- CSS
- JavaScript
- IDE: Visual Studio Code


## How It Works

- Enter a city name in the search bar
- View real-time weather data for that city (temperature, humidity, wind speed)
- Explore additional five-day forecasts presented in a card layout
- The app works smoothly across desktop and mobile devices
