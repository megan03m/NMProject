# IBM-FE-Live Weather Dashboard
A dynamic web application that provides real-time weather updates for any city, featuring instant weather conditions, five-day forecasts, search history, and an intuitive user interface.


## Features
-Search live weather details by city (temperature, humidity, wind speed, UV index)
-Real-time current weather and five-day forecast
-Search history panel with clear option
-Responsive and user-friendly interface
-Clear error states and visual feedback


## Technologies Used
-HTML for webpage structure and content.​
-CSS for styling and responsive design.​
-JavaScript for dynamic behavior, fetching weather data, and interactivity.​
-IDE: Visual Studio Code (for all code editing)
